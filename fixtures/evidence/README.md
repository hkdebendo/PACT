# Evidence fixtures

Neutral, brand-free images for the demo scenario. Generated by `npm run fixtures` (placeholders) unless replaced by real photos.

| File | Used for |
|---|---|
| order_conforming.jpg | production photo that matches the order (50 white t-shirts, blue star) |
| order_wrong_item.jpg | wrong item (mugs) — the Verifier must reject it |
| tracking_valid.png | courier tracking page showing "Delivered" |
| delivery_partial.jpg | dispute variant: 12 of 20 tote bags |

The recorded model answers in `fixtures/llm-cache/` are keyed by the sha256 of these files: after replacing a file, re-record with a Meta key (`LLM_MODE=live npm run demo`).
